# 🌌 Galaxy Maze Explorer (10x10)

Aplikasi interaktif untuk memvisualisasikan dan membandingkan algoritma **BFS (Breadth-First Search)** dan **DFS (Depth-First Search)** dalam menyelesaikan labirin antariksa berukuran 10x10.

## ✨ Fitur
- **Tema Galaksi:** Tampilan antarmuka gelap dengan aksen neon yang estetik.
- **Animasi Mulus:** Penelusuran labirin divisualisasikan seperti ular alien (👾) yang berjalan menyambung tanpa jeda/kedip.
- **Penanda Unik:** Menggunakan emoji Astronot (👨‍🚀) sebagai titik awal dan UFO (🛸) sebagai tujuan.
- **Interaktif:** Tombol kustom untuk menjalankan BFS, DFS, dan mengulang animasi.
